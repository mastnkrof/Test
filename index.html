HTML

Ustvaril sem preprosto spletno stran z datotekami index.html, style.css, main.js in mapo s slikami.

Vse skupaj bom posredoval na svoj GitHub.

Seznam najpogostejših html elementov:

  • head - glava
  • body - telo
  • h1 - največji naslov
  • p - odstavek
  • img - slika

GIT

Namestil sem git na računalnik in ga spravil v delujoče stanje.

Posredoval sem to spletno stran.

Uporaba GIT

Elemente, ki sem jih želel posredovati sem dodal h commitom z ukazom:

git add datoteka

Za tem sem commital z ukazom:

git commit komentar

Na koncu pa še vse skupaj posreduješ na GitHub z ukazom:

git push
